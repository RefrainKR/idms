# 결정

- 소스 파일명과 ES 모듈 분리는 유지합니다.
- 캐시 키는 사용자용 `APP_VERSION`과 분리하고 배포 커밋 SHA 앞 12자를 사용합니다.
- 변환 대상은 배포 사본의 HTML `script[src]`·CSS `link[href]` 및 JavaScript의 정적·동적 로컬 모듈 참조입니다.
- `http:`, `https:`, `//`, `data:`, `blob:` 등 외부·특수 URL은 변환하지 않습니다.
- 변환 스크립트는 외부 npm 패키지 없이 현재 Actions runner의 Node.js로 실행합니다.
- 스크립트가 변환 직후 전체 산출물을 다시 검사하며, 누락 시 0이 아닌 종료 코드로 배포를 막습니다.
- 현재 구현은 검증용이며 사용자 승인 전에는 공개하지 않습니다.
