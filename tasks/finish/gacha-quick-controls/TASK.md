## 허용 범위

- 3성 가챠의 기존 사용자 설정 입력을 결과 가까이의 작은 빠른 설정 바로 이동
- 활성 서브탭에 맞는 입력만 표시
- 빠른 설정 바의 섹션 내부 sticky 동작
- 목표 확률 입력 접근성 개선
- 재사용 가능한 공통 빠른 설정 CSS
- 탭별 제어 visibility 설정의 소규모 의미 정리
- 표시 버전과 정적 자산 캐시 키를 `1.12.1`로 갱신
- 3성 배너 요약 문구 압축과 프리셋의 가챠 설정 dialog 내부 재배치
- 기존 3성 초기화 버튼을 모든 LocalStorage를 지우는 앱 전체 초기화로 변경하고 반응형 사이드바에 배치
- 사용자 승인에 따라 같은 구조를 생일·콜라보·2성에 각 입력 의미를 보존해 확장
- 공통 dialog와 모바일 차트/확률표 전환 동작을 BaseGachaViewModel에서 재사용
- 필요한 문서·JSDoc 및 검증 스크립트 조정

## 금지 범위

- 가챠 확률 계산 또는 게임 규칙 변경
- 입력 요소 복제 및 별도 동기화 로직 추가
- 스탭업 주요 구간별 효과 표 구현
- 과금 효율 UI의 동시 개편
- 프레임워크·빌드 시스템·백엔드 도입
- 관련 없는 CSS/JavaScript 리팩토링

## 완료 조건

- 원본 입력 ID와 Observable 연결을 유지하면서 3성 빠른 설정 바에서 값을 수정할 수 있음
- 픽업 획득·총 획득에서는 저격/아무나, 픽업 수, 일반·스탭업 횟수를 바로 수정할 수 있음
- 일반 vs 스탭업에서는 저격/아무나, 픽업 수, 목표 확률을 바로 수정할 수 있음
- 무돌에서는 일반·스탭업 횟수를 바로 수정할 수 있음
- 서브탭 전환 시 빠른 설정 바 높이와 차트 시작 위치가 불필요하게 흔들리지 않음
- sticky 바가 현재 가챠 섹션 밖까지 따라가지 않음
- 모바일과 데스크톱에서 전역 가로 넘침·중대한 겹침이 없음
- 프리셋, LocalStorage 복원과 입력 상한이 기존처럼 동작함
- 전체 설정 초기화가 확인 후 LocalStorage의 모든 값을 지우고 앱 기본값으로 다시 시작함
- 대표 3성 계산 결과가 변경 전후 동일함
- 표시 버전과 정적 자산 캐시 키가 `1.12.1`로 일치함
- 생일·콜라보·2성에서도 배너 요약, 가챠 설정 dialog, 탭별 빠른 설정과 고정 결과 영역이 정상 동작함
