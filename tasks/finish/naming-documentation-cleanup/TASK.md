# 네이밍·문서·CSS 의미 정리

## 목적

현재 구현의 계산 동작과 정적 MVVM 구조를 보존하면서 네이밍, 한국어 UI 표현, 주석/JSDoc, 문서 경로, CSS 책임과 상태 클래스의 의미를 명확하게 정리합니다.

## 허용 범위

- 의미가 검증된 변수·필드·전략명 정리
- 간결한 한국어 UI 용어 정리
- 주석, JSDoc, 문서 경로 및 설명 정리
- 중복·미사용 CSS 제거와 공통 스타일 재사용
- 동작 보존 검증

## 금지 범위

- 새로운 가챠 분석 기능 또는 지표
- 확률 알고리즘이나 게임 규칙 변경
- 프레임워크, 빌드 시스템, 백엔드 도입
- `../gacha-analysis/IDEAS.md`의 미승인 아이디어 구현

## 완료 조건

- 계산 Core의 의도하지 않은 변경이 없음
- 네이밍과 UI 용어가 코드 의미 및 게임 규칙과 일치함
- CSS 선택자·변수·동적 상태 계약이 검증됨
- 활성 문서 경로가 현재 트리와 일치함
- Sol 역할이 실제 diff와 검증 결과를 승인함
