# 결정 사항

- 정적 GitHub Pages, Vanilla JavaScript, ES modules, MVVM 구조를 유지합니다.
- 계산 규칙이 불명확한 경우 네이밍 정리 단계에서 동작을 수정하지 않습니다.
- UI에는 `일반`, `스탭업`, `천장`, `셀렉 티켓`, `Best (성공)`, `Worst (폭사)`처럼 간결한 한국어 게임 용어를 사용합니다.
- 내부 전략 메타데이터는 영어를 사용할 수 있지만 구현용 식별자나 장문의 전략 설명을 버튼에 노출하지 않습니다.
- `common.css`에는 가챠와 과금 화면이 공유하는 기반 규칙을 두고, `gacha.css`와 `payment.css`에는 화면 전용 규칙을 둡니다.
- `docs/UPDATE.md`는 유지되는 개발 변경 이력이며, 완료된 작업 문서와 폐기 문서의 저장소가 아닙니다.
- 이 작업의 기능 변경은 금지하며 신규 분석 후보는 별도 `gacha-analysis` 작업에서 검토합니다.
