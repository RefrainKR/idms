# 프로젝트 공유 문서

이 디렉터리는 한 명의 개발자와 코딩 에이전트가 함께 참고하는 현재 프로젝트 지식입니다. 개발자는 오래된 기억을 보완하거나 게임 사양 변경을 전달하기 위해 이 문서들을 자유롭게 수정·추가할 수 있습니다.

## 운영 원칙

- `game/`에는 현재 확인된 가챠·과금 규칙과 근거를 기록합니다.
- 게임 업데이트로 규칙이 바뀌면 개발자가 문서를 먼저 고쳐도 됩니다. 에이전트는 해당 변경을 중요한 입력으로 취급하되, 계산 동작을 바꾸기 전 실제 코드·배너 근거와 함께 검증합니다.
- 불확실한 내용은 확정 사실처럼 쓰지 말고 확인 필요 상태와 근거를 함께 남깁니다.
- 현재 사양 문서와 실제 코드가 다르면 추측해서 계산을 바꾸지 않고 차이를 개발자에게 알립니다.
- 다음 개발 아이디어와 합의는 저장소 루트 `NEXTROAD.md`, 에이전트 작업 패킷은 루트 `tasks/`, 완료 변경 이력은 루트 `DEVLOG.md`에서 관리합니다.
- 완료됐거나 더 이상 쓰지 않지만 보존 가치가 있는 공유 Markdown은 필요한 경우 `old/`에 둡니다. 현재 규칙 문서나 활성 작업 문서를 `old/`에 넣지 않습니다.

## 문서 책임

| 위치 | 주 용도 | 기본 편집 주체 |
|---|---|---|
| `NEXTROAD.md` | 다음 개발 논의와 아이디어 | 개발자 + Sol |
| `scsfp/docs/` | 현재 프로젝트·게임 지식 | 개발자 + 에이전트 |
| `DEVLOG.md` | 완료 변경과 설계 맥락 | 코딩 에이전트 |
| `tasks/` | 승인된 구현과 Sol↔Terra 인계 | 코딩 에이전트 |
| `AGENTS.md` | 장기 작업 규칙 | 개발자 지시에 따라 에이전트 관리 |
