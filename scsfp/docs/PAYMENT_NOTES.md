## 미확인 패키지 데이터

### iOS 무돌 전용 패키지 (확인 필요)

iOS에 무돌을 직접 판매하는 패키지가 존재하는 것으로 파악됨. 상세 정보 미확인.

```
알려진 구성 (추정):
├─ 가격: ₩8,800
├─ 무돌: 50개
├─ 가챠 티켓: 2장
└─ 판매 조건: 미확인 (상시/한정 여부)
```

**미확인 항목**:
- 정식 패키지 명칭
- 판매 조건 (상시 상시/기간 한정)
- 구성 정확도 (티켓 수, 무돌 수)
- ASOBI/Android 동일 패키지 존재 여부

## 계산 방법론 검토

### 현재 방식의 한계: 시즌 페스 순환 의존성

**현재 방식** (`calculateSeasonFesRainbowPrice`):
- ASOBI(¥1,960 / 2,250무료돌 / 165무돌) vs iOS(₩17,000 / 2,000무료돌 / 150무돌) 비교
- iOS 단가 = iOS 가격 ÷ iOS 유효 gem
- ASOBI 정규화 후 잔액 = 무돌 15개 가격

**문제**:
iOS 패키지에 이미 무돌 150개가 포함되어 있으므로
`iOS 단가`에 무돌 가치가 내포됨 → 무돌 가격을 구하려는데 무돌 가격이 이미 포함된 단가를 사용 → **순환 의존**

`iOS 단가 = (무료돌값 + 무돌150×R + 티켓값) / 유효gem`
→ R을 구하기 위해 R이 포함된 단가를 사용

**결과**: 시즌 페스의 무돌 가격은 근사치이며, 실제 무돌 가치가 클수록 오차도 커짐.

**참고**: D/E/F팩 계산 (`calculateRainbowCrystalPrices`)은 iOS에 무돌이 없으므로 순환 의존 없이 정확함.

---

### 개선 방향: 직접 가격 역산

iOS 무돌 전용 패키지 (₩8,800 = 티켓 2장 + 무돌 50개)를 이용한 직접 산출:

```
무돌 1개 가격(₩) = (₩8,800 - 티켓 2장 × 티켓단가_KRW) / 50
```

**장점**:
- 순환 의존 없음 (무돌 가격을 직접 역산)
- 시즌 페스 계산도 이 값을 기준으로 검증 가능

**선결 조건**:
1. iOS 무돌 패키지 상세 정보 확인 (구성, 명칭, 판매 조건)
2. 티켓 단가를 어떻게 처리할지 결정
   - 현재: `ticketValue` 사용자 설정 (무료돌 환산)
   - 개선: 무돌 가격 역산 후 티켓 가치와 교차 검증 가능
