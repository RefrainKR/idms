# GAME_RULES.md

THE IDOLM@STER Shiny Colors Song for Prism의 게임 시스템 사양 문서입니다.

---

## 카드 종류

- **프로듀스 카드 (P카드)**: 1성 ~ 3성 등급
- **서포트 카드 (S카드)**: U → UR → SSR 등급
- **리뉴얼 이후**: 가챠에서 P카드와 S카드가 동시 배출
  - 3성 가챠: 픽업 획득 시 P카드(3성) + S카드(SSR) 동시 획득
  - 2성/생일 가챠: S카드 없음 (P카드만 배출)

## 재화 종류

- **무료돌 (프리즘 쥬얼)**: 일반 가챠에만 사용 가능
- **유료돌 (프리즘 쥬얼)**: 일반 가챠 + 스탭업 가챠 모두 사용 가능
- **무돌 (虹の結晶)**: P카드·S카드 공용 한계돌파 재화. 범용성이 높아 모든 카드에 사용 가능
- **날개 (Wings)**: P카드 전용 한계돌파 재화. P카드 획득 시 지급되며, 픽업 여부·New/중복 여부에 따라 지급량이 다름. 무돌로 교환 가능 (누진제)
- **피스 (Piece)**: S카드 전용 한계돌파 재화. 상세 규칙은 추후 추가 예정

---

## 날개 (Wings) 시스템

### 날개-무돌 교환 비율 (누진제)

날개는 무돌로 구매할 수 있으며, 카드별 구매 횟수가 늘어날수록 단가가 올라갑니다.

> **누진 기준**: 카드별 구매 횟수 (리셋). 가챠 획득 시 무료로 받은 날개는 카운트에 포함되지 않음.

| 구간 (카드별 누적 구매 횟수) | 개당 무돌 | 소계 |
|-----------------------------|-----------|------|
| 1 ~ 20번째 | 1무돌 | 20무돌 |
| 21 ~ 40번째 | 2무돌 | 40무돌 |
| 41 ~ 60번째 | 3무돌 | 60무돌 |
| 61 ~ 80번째 | 4무돌 | 80무돌 |
| 81개 이상 | **5무돌 고정** | — |

### 한계돌파 비용 (P카드 3성 기준)

P카드 3성 → 5성 달성에 날개 **500개** 필요.

| 구간 | 필요 날개 |
|------|----------|
| 3성 → 4성 | 200개 |
| 4성 → 5성 | 300개 |
| **합계** | **500개** |

New(첫 획득) 시 날개 60개 지급되므로 부족한 440개를 무돌로 채울 경우:

```
 1~ 20번째 구매:  20개 × 1 =   20무돌
21~ 40번째 구매:  20개 × 2 =   40무돌
41~ 60번째 구매:  20개 × 3 =   60무돌
61~ 80번째 구매:  20개 × 4 =   80무돌
81~440번째 구매: 360개 × 5 = 1,800무돌
────────────────────────────────────────
합계: 2,000무돌 (New 획득 후 5성까지 무돌만 사용 시)
```

> 2성 카드의 날개 획득량 및 한계돌파 비용은 3성과 다르며, 별도 추가 예정.

## 가챠 티켓

일반 가챠를 1회 돌릴 수 있는 아이템입니다.

- **사용 가능 가챠**: 정규 가챠 (한정 / 통상 / PJ 등)
- **사용 불가 가챠**: 콜라보 가챠, 생일 가챠 등 특수 가챠
- **10연 보너스 없음**: 10장을 연속 사용해도 2성/SR 확정 등 10연 보너스를 받지 못함
- **스탭업 불가**: 스탭업 가챠에 사용 불가

### 가챠 티켓 가치 환산

일반 가챠 1회 비용 = 250돌 (무료돌/유료돌 공통)이므로,
가챠 티켓 1장 ≈ **무료돌 250개 (기간 제한 30일)** 에 해당합니다.

## 유료돌 플랫폼 격리 시스템

게임은 4개 플랫폼에서 실행 가능하며, **유료돌은 플랫폼별로 완전 격리**됩니다.

### 플랫폼 종류

1. **DMM판** (PC): Windows/Mac 브라우저 기반
2. **Android판**: Google Play 스토어
3. **iOS판**: Apple App Store
4. **아소비 스토어**: 구매 전용 웹사이트 (플랫폼 아님)

### 유료돌 격리 규칙

**무료돌 (이벤트 보상 등)**:
- ✅ 모든 플랫폼에서 공유
- 어느 플랫폼에서든 획득하면 모든 플랫폼에서 사용 가능

**유료돌 (과금)**:
- ❌ 플랫폼별로 완전 격리
- 다른 플랫폼에서 구매한 유료돌은 **존재하지 않는 것처럼 보임**

### 플랫폼별 유료돌 사용 규칙

```
DMM판
├─ 구매: DMM에서만
├─ 사용: DMM 구매분만
└─ 타 플랫폼 돌: 보이지 않음

Android판
├─ 구매: Android 스토어 또는 아소비 스토어
├─ 사용: Android + 아소비 구매분 (합산)
└─ 타 플랫폼 돌: 보이지 않음

iOS판
├─ 구매: iOS 스토어 또는 아소비 스토어
├─ 사용: iOS + 아소비 구매분 (합산)
└─ 타 플랫폼 돌: 보이지 않음

아소비 스토어
├─ 성격: 구매 전용 웹사이트 (플랫폼 아님)
├─ 목적: 구글/애플 수수료(~30%) 회피
├─ 구매 방법: 공식 웹사이트에서 직접 결제
└─ 구매한 돌: Android + iOS 양쪽에서 사용 가능
```

### 격리 시스템 예시

**시나리오**: 유저가 계정 하나로 여러 플랫폼 사용
```
1. DMM에서 유료돌 1000개 구매
2. Android로 전환
   → DMM 유료돌 1000개는 보이지 않음
   → Android/아소비 구매분만 보임

3. 아소비 스토어에서 500개 구매
4. Android로 접속
   → Android 구매분 + 아소비 500개 = 합산 표시
5. iOS로 접속
   → iOS 구매분 + 아소비 500개 = 합산 표시
6. DMM으로 접속
   → DMM 유료돌 1000개만 표시 (아소비 500개 안 보임)
```

### 플랫폼 간 유료돌 흐름도

```
         무료돌 (공유)
         ↕   ↕   ↕   ↕
       ┌────┬────┬────┬────┐
       │DMM │And.│iOS │Asobi│ ← 구매 지점
       └────┴────┴────┴────┘
         ↓    ↓    ↓    ↓
       ┌────┬────┬────┬────┐
       │DMM │And.│iOS │공유 │ ← 사용 가능 플랫폼
       │전용│전용│전용│And+│
       │    │+공유│+공유│iOS │
       └────┴────┴────┴────┘
```

**중요**:
- 하나의 계정으로 모든 플랫폼 접속 가능
- 무료돌은 완전 공유
- 유료돌은 플랫폼별 지갑(wallet)처럼 분리
- 아소비 스토어만 예외적으로 Android+iOS 공유
