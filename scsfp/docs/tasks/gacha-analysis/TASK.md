# 가챠 분석 개선 검토

## 목적

`IDEAS.md`의 후보를 게임 규칙, 현재 계산 구조, 사용자 효용을 기준으로 검토하고 사용자가 명시적으로 선택한 항목만 별도 구현 범위로 확정합니다.

## 현재 범위

- 아이디어의 가치와 규칙 근거 검토
- 기존 기능과의 중복 및 계산 비용 검토
- 구현 전 필요한 게임 규칙 질문 정리
- 선택된 아이디어의 완료 조건 작성

## 현재 금지 범위

- 사용자가 선택하지 않은 아이디어 구현
- 검증되지 않은 게임 규칙을 전제로 한 계산 변경
- 네이밍 정리와 신규 분석 기능을 한 diff에 혼합

## 구현 진입 조건

- 사용자가 구현할 아이디어를 명시적으로 선택함
- Sol 역할이 `DECISIONS.md`에 규칙·범위·완료 조건을 기록함
- 상태가 `ready-for-terra`로 변경됨
- 구현용 브랜치가 사용자 승인에 따라 지정됨
