# GACHA_SYSTEM.md

THE IDOLM@STER Shiny Colors Song for Prism 가챠 시스템 상세 사양 문서입니다.

> 실제 코드에서 사용하는 수치는 `js/core/Constants.js`를 기준으로 합니다.

---

## 가챠 공통 개념

- **픽업**: 해당 가챠의 특정 목표 카드들
  - 3성 가챠: 최고 등급(3성)이 나와도 픽업이 아닐 수 있음 (픽뚫 발생)
  - 2성 가챠: 2성이 나오면 100% 픽업 (픽뚫 없음)
  - 생일 가챠: 픽업 1개 고정
- **천장 (셀렉 티켓)**: 일정 횟수 도달 시 원하는 픽업 카드 선택 가능
- **랜덤 티켓 (픽업 티켓)**: 픽업 중 랜덤으로 1개 획득 (천장의 너프 버전)
- **주(周)**: 스탭업 가챠의 특정 단위 (3성: Step1~4 = 40회)

---

## 3성 가챠 시스템

### 일반 가챠

- 확률 조정 없는 기본 가챠
- 픽업 확률: 사용자 설정 (일반적으로 1.0% 내외)

### 스탭업 가챠 (유료돌 전용)

- **주(周) 구조**: Step1~4 (총 40회) = 1주, 최대 주회 수는 가챠마다 다름
- **주회 보상**: 각 주 Step4 완료 시 보상 1개 (없음 / 랜덤 티켓 / 셀렉 티켓)

스탭업 가챠는 **10회 1세트(Step)** 단위로 구성되며, Step1~4를 순서대로 진행하면 1주(40회) 완료입니다.

**Step별 배출 확률**:

| Step | 구간 | 1~9회째 확률 | 10회째 확률 | 비고 |
|------|------|-------------|-------------|------|
| Step1 | 1~10회 | 기본 확률 | 기본 확률 | 보정 없음 |
| Step2 | 11~20회 | 기본 확률 | 3성+SSR **2배** | 20회째(해당 Step 마지막 회)만 2배 |
| Step3 | 21~30회 | 3성+SSR **2배** | 3성+SSR **2배** | 해당 Step 전 회차 2배 |
| Step4 | 31~39회 | 기본 확률 | — | |
| Step4 | 40회째 | — | 3성 **60%** + SSR **40%** | 마지막 회 자체가 확정 배출 (보너스 추가 아님), **픽업 확률은 불변** |

> **시뮬레이터 단순화**: Step2/Step3의 3성+SSR 2배 보정은 픽업 확률과 무관하므로 시뮬레이션에서 무시. 오직 픽업 획득 확률에만 집중.

### 천장 시스템

- 일반 + 스탭업 합산 **200회**마다 천장 1회 (셀렉 티켓)
- 횟수는 가챠 간 공유됨

## 2성 가챠 시스템

### 일반 가챠

- **픽뚫 없음**: 2성이 나오면 100% 픽업
- **확률 계산**: `개별 픽업 확률 = 전체 2성 확률 / 픽업 개수`
- **10회 보정**: 10회째에 2성 획득 확률 **95%** 보정
- **천장**: **100회**마다 1회 (일반 가챠 전용)

### 스탭업 가챠 (유료돌 전용, 그룹별)

- **그룹 구성**: 보통 4개 그룹 (A, B, C, D)으로 분할
- **확률 계산**: `개별 픽업 확률 = 전체 2성 확률 / 그룹별 픽업 개수`
- **천장**: 그룹별 합산 **50회**마다 1회 (스탭업 가챠 전용, 일반 천장과 독립)

**Step별 배출 확률**:

| Step | 구간 | 2성 확률 | 비고 |
|------|------|----------|------|
| Step1 | 1~5회 | 기본 확률 | 5회째 2성 **100%** 확정, 1번만 가능 |
| Step2 | 6~15회 (이후 반복) | 기본 확률 | 10회마다 마지막 회 2성 **100%** 확정 |

## 무돌 (虹の結晶) 시스템

### 개요

- **용도**: 카드 등급 업그레이드 (P카드 + S카드 모두 사용 가능)
- **특징**: 카드별 날개/피스와 달리 모든 카드에 범용으로 사용 가능한 재화

### 가챠 배출 확률 (3성 가챠 기준)

리뉴얼 이후 3성 가챠에서는 P카드와 S카드가 동시 배출됩니다.

**일반 회차 (1~9회, 11~19회, ...)**:

| 카드 | 등급 | 확률 | 무돌 획득량 |
|------|------|------|-------------|
| P카드 | 3성 | 5% | 25개 |
| P카드 | 2성 | 15% | 5개 |
| P카드 | 1성 | 33% | 1개 |
| S카드 | SSR | 3% | 25개 |
| S카드 | SR | 5% | 5개 |
| S카드 | R | 39% | 1개 |

> 합계: P카드 53% + S카드 47% = 100%

**10회째 보정 (10연 기준 마지막 회)**:

P카드 1성 → 2성 이상 확정, S카드 R → SR 이상 확정으로 확률 재배분:

| 카드 | 등급 | 확률 | 비고 |
|------|------|------|------|
| P카드 | 3성 | 5% | 동일 |
| P카드 | 2성 | ~61.333% | 1성 46.333% 흡수 |
| P카드 | 1성 | 0% | 2성으로 이동 |
| S카드 | SSR | 3% | 동일 |
| S카드 | SR | ~30.667% | R 25.667% 흡수 |
| S카드 | R | 0% | SR로 이동 |

### 1회 기대값 계산

```
P카드 1회 기대값 = 0.05×25 + 0.15×5 + 0.33×1 = 1.25 + 0.75 + 0.33 = 2.33개
S카드 1회 기대값 = 0.03×25 + 0.05×5 + 0.39×1 = 0.75 + 0.25 + 0.39 = 1.39개
1회 합계 기대값 = 3.72개
```

**10연 기대값** (10회째 보정 포함):
```
P카드 9회 = 2.33×9 = 20.97개
P카드 10회째 = 0.05×25 + 0.61333×5 + 0×1 ≈ 1.25 + 3.067 = 4.317개
S카드 9회 = 1.39×9 = 12.51개
S카드 10회째 = 0.03×25 + 0.30667×5 + 0×1 ≈ 0.75 + 1.533 = 2.283개
10연 합계 = (20.97 + 4.317) + (12.51 + 2.283) = 40.08개
```
