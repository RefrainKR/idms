# v1.8.0 버그 수정 - Total Count Chart

## 문제점

총 획득 수 차트 (`resultChartTotal3`, `resultChartTotal2`, `resultChartTotalBirthday`)에서 두 가지 문제 발생:

1. **매우 작은 확률이 차트에서 제외됨**
   - THRESHOLD = 0.0001 (0.01%)로 설정되어 있어, 0.01% 미만의 확률은 차트 범위에서 제외
   - 예: 0.005% 확률은 차트에 표시되지 않음

2. **`.toFixed()` 직접 사용**
   - Line 162에서 `(val * 100).toFixed(2)` 사용
   - v1.8.0의 경계값 표기법이 적용되지 않음

## 발견 위치

**파일**: `js/view/ResultView.js`

1. **Line 117**: THRESHOLD 값이 너무 높음 (0.01%)
2. **Line 162**: `.toFixed(2)` 직접 사용

## 수정 내용

### 1. THRESHOLD 값 조정 (Line 117-118)

**Before**:
```javascript
// 유의미한 구간 탐색 (0.01%)
const THRESHOLD = 0.0001;
```

**After**:
```javascript
// 유의미한 구간 탐색 (0.001% 이상)
const THRESHOLD = 0.00001;
```

**효과**:
- 0.001% 이상의 확률은 모두 차트 범위에 포함
- 매우 낮은 확률도 차트에서 볼 수 있음

---

### 2. 데이터 포맷팅 개선 (Line 159-167)

**Before**:
```javascript
for (let k = startK; k <= endK; k++) {
    const val = transformedDP[k] || 0;
    labels.push(`${k}${suffix}`);
    data.push((val * 100).toFixed(2));
    tooltipVals.push(Formatter.formatProbability(val));

    // Peak 지점 강조 (모드 상관없이 항상 표시)
    colors.push(k === maxIndex ? '#45a247' : '#e3f2fd');
}
```

**After**:
```javascript
for (let k = startK; k <= endK; k++) {
    const val = transformedDP[k] || 0;
    labels.push(`${k}${suffix}`);
    data.push(val * 100);  // Keep as number for chart rendering
    tooltipVals.push(Formatter.formatProbability(val));

    // Peak 지점 강조 (모드 상관없이 항상 표시)
    colors.push(k === maxIndex ? '#45a247' : '#e3f2fd');
}
```

**변경 이유**:
- 데이터를 숫자로 유지 (문자열로 변환하지 않음)
- ChartAdapter.renderBarChart의 datalabels formatter에서 `Formatter.probabilityBounded()` 적용
- 차트 레이블에서 경계값 표기 (`0.01%↓`) 가능

---

### 3. ChartAdapter 별칭 메서드명 통일

**Before**:
```javascript
// Pie Chart (Line 53)
const percentText = Formatter.formatProbabilityBounded(value / 100, 2);

// Bar Chart (Line 118)
const formatted = Formatter.formatProbabilityBounded(parseFloat(value) / 100, 2);
```

**After**:
```javascript
// Pie Chart (Line 53)
const percentText = Formatter.probabilityBounded(value / 100, 2);

// Bar Chart (Line 118)
const formatted = Formatter.probabilityBounded(parseFloat(value) / 100, 2);
```

**이유**:
- 별칭 대신 새 메서드명 사용
- 코드 일관성 향상

---

## ChartAdapter의 기존 동작 확인

`renderBarChart`의 datalabels formatter (Line 116-122):
```javascript
formatter: (value) => {
    // 매우 작은 값도 화살표 표기로 표시
    const formatted = Formatter.probabilityBounded(parseFloat(value) / 100, 2);
    // 정확히 0%인 경우만 숨김
    if (formatted === '0.00%') return null;
    return formatted;
}
```

**이미 올바르게 구현되어 있음**:
- `probabilityBounded()` 사용으로 경계값 표기 적용
- 정확히 `0.00%`인 경우만 숨김 (매우 작은 값은 `0.01%↓`로 표시)

## 테스트 시나리오

### Scenario 1: 매우 낮은 확률 (0.005%)

**Before**:
- 차트 범위에서 제외 (THRESHOLD = 0.01%보다 작음)
- 차트에 표시되지 않음

**After**:
- 차트 범위에 포함 (THRESHOLD = 0.001%보다 큼)
- 차트에 표시되지만, 레이블 없음 (Bar Chart는 높이가 매우 낮음)
- 툴팁에서 확인 가능

### Scenario 2: 경계값 (0.0001% ~ 0.01%)

**Before**:
- 차트에 `0.00%` 표시 (혼란스러움)

**After**:
- 차트에 `0.01%↓` 표시 (명확함)

### Scenario 3: 일반 확률 (1% 이상)

**Before/After 모두 동일**:
- 정상적으로 표시 (`1.23%`, `50.00%` 등)
