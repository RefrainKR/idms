# v1.8.0 버그 수정 - Efficiency Chart

## 문제점

효율 차트 (`efficiencyChart`, `efficiencyChart2`)에서 확률 표시가 여전히 `.toFixed()`를 사용하고 있어 v1.8.0의 경계값 표기법이 적용되지 않음.

## 발견 위치

1. **GachaResultView.js:292-293** - 차트 데이터 준비
2. **GachaResultView.js:346-353** - 요약 텍스트
3. **ChartAdapter.js:180** - 라인 차트 툴팁 레이블

## 수정 내용

### 1. 차트 데이터 준비 (GachaResultView.js:292-293)

**Before**:
```javascript
const finalStep = stepupData.map(v => parseFloat(v[modeKey]).toFixed(3));
const finalNorm = normalData.map(v => parseFloat(v[modeKey]).toFixed(3));
```

**After**:
```javascript
const finalStep = stepupData.map(v => parseFloat(v[modeKey]));
const finalNorm = normalData.map(v => parseFloat(v[modeKey]));
```

**이유**:
- 데이터를 숫자로 유지하여 차트가 정확한 값을 렌더링
- 문자열로 변환하지 않음 (차트 내부에서 포맷팅)

---

### 2. 요약 텍스트 (GachaResultView.js:346-353)

**Before**:
```javascript
const sVal = finalStep[limitIdx];
const nVal = finalNorm[limitIdx];

summaryEl.innerHTML = `
    ...
    (스탭업 ${sVal}% vs 일반 ${nVal}%)
`;
```

**After**:
```javascript
const sVal = finalStep[limitIdx];
const nVal = finalNorm[limitIdx];
const sValText = Formatter.probabilityBounded(sVal / 100, 3);
const nValText = Formatter.probabilityBounded(nVal / 100, 3);

summaryEl.innerHTML = `
    ...
    (스탭업 ${sValText} vs 일반 ${nValText})
`;
```

**효과**:
- 매우 낮은 확률: `0.001%↓` 표시
- 매우 높은 확률: `99.999%↑` 표시
- 일반 확률: `50.123%` (기존과 동일)

---

### 3. 라인 차트 툴팁 (ChartAdapter.js:180)

**Before**:
```javascript
label: (context) => {
    let label = context.dataset.label.split(' ')[0] || '';
    return ` ${label}: ${context.raw}%`;
},
```

**After**:
```javascript
label: (context) => {
    let label = context.dataset.label.split(' ')[0] || '';
    const probText = Formatter.probabilityBounded(context.raw / 100, 3);
    return ` ${label}: ${probText}`;
},
```

**효과**:
- 툴팁에도 경계값 표기 적용
- 차트 전체에서 일관된 표기법 사용

## 검증 결과

### Before (v1.8.0 초기)
```
요약: (스탭업 0.123% vs 일반 0.000%)  ← 0.000%는 혼란스러움
툴팁: 스탭업: 0.123%
```

### After (v1.8.0 수정)
```
요약: (스탭업 0.123% vs 일반 0.001%↓)  ← 명확함!
툴팁: 스탭업: 0.123%
      일반: 0.001%↓
```
